Help & Quick Reference

Quick start

  1. Fill in the form on the New Voucher tab. The BV NO. auto-increments from 158201.
  2. Start typing in To (Property / Airline) — the 301-lodge autocomplete filters as you type.
  3. Click Save — stored in your browser and appears on the History tab.
  4. Click Print / Save PDF — the browser print dialog opens; choose "Save as PDF" as the destination.
  5. Click Email — opens your default email client with subject and body pre-filled. Attach the PDF you just saved.
  6. Click New to blank the form and issue the next BV NO.

Data storage

Everything is stored in your browser's localStorage. That means:

  • No login, no server, no fees.
  • Works offline once the page has loaded once.
  • Data does NOT sync across browsers or devices. Use Backup / Restore to export a JSON file to move between machines.
  • If you clear browser data / cookies, vouchers may be lost — backup regularly.

Dashboard metrics

Voucher Notes

The last field on the form is internal only. It is stored with the voucher and shown in History, but is NEVER printed on the voucher itself. Safe for confidential comments.

Adjusting the BV number

The current counter is saved in localStorage under scs_bv_counter. If you need to reset, use the browser DevTools console: localStorage.setItem('scs_bv_counter', 158201).
